SYON ALL IN ONE 관리자 화면 v1 (시안)

index.html을 브라우저에서 열면 됩니다. 별도 설치 없음.
가상 데이터 등록, 수정, 삭제, 검색, 상태 필터 및 집계가 작동하도록 구성했습니다.
데이터는 메모리에만 유지되며 새로고침하면 초기화됩니다. 실고객 정보 입력 금지.

실제 운영 전 필수:
1. 기존 도메인 소유 여부 확인, DNS에 admin 서브도메인을 호스팅 서비스가 지정한 레코드로 설정, HTTPS 적용.
2. 서버 측 관리자 로그인, MFA, 세션 및 접근권한 검증. 정적 HTML이나 주소 숨김은 보안이 아닙니다.
3. 접근 제어된 DB, 서버 API, 암호화, 감사 로그, 백업 및 개인정보 보존/삭제 정책.
4. 상담 접수 연동, 거래처별 정책 및 정산 기준 확정, 실제 개통/정산 검증.
이 파일은 배포 및 실운영 서버 연결이 이루어지지 않은 화면 시안입니다.
